# Hybrid AI Model for Cryptocurrency Price Prediction

## Overview

A final-year project focused on cryptocurrency price prediction
using high-frequency market data and machine learning.

## Technologies

- Python
- Pandas and NumPy
- Scikit-learn
- XGBoost
- Jupyter Notebook

## Project Structure

- `src/` - Source code
- `notebooks/` - Data cleaning and experimentation
- `data/` - Raw and processed datasets (not uploaded)

python -m venv .venv
